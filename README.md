## 🔵 大项目企划 / Project Ideas / Upcoming  

- **HoundAlphaMeta (HAM)**  
  函数式编程语言，逻辑结构非传统，与常见语言和普通函数式语言都不一样。  
  我个人认为它非常完美：非常函数式、面向对象、支持元编程、简单易学……如果实现起来不那么难就好了。  
  文档在 HAM 仓库，我考虑重写 3.0（因为 2.0 逻辑有 BUG）。  
  如果你也喜欢函数式哲学，对计算机底层有一定了解，我们可以做朋友（听起来有点强制 qwq）。  
  *尚未实现*  
  A functional programming language with a completely non-traditional logic structure. Different from both mainstream languages and standard functional ones.  
  Personally, I think it’s perfect: very functional, object-oriented, meta-programming friendly, and simple to learn… if only implementation weren’t so hard.  
  Docs in HAM repo. Planning v3 rewrite because v2 has logic bugs.  
  If you love FP philosophy and low-level computing, let’s be friends (okay, that sounded a bit pushy).  
  *Not implemented yet*  

- **HoundTilingDesktop**  
  平铺窗口管理器，目标平台：Linux/Wayland。  
  设计理念：让使用层叠窗口管理器或平板的用户无缝体验平铺。  
  灵感来源：Niri（无限滚动），结合自然交互（无需学习或学习曲线平缓）与窗口生命周期分离（窗口消失但位置保留）。  
  计划语言：C++ 或 Rust，也可能是 River WM 等。  
  *尚未开始*  
  Tiling window manager for Linux/Wayland.  
  Designed to let floating-window or tablet users experience tiling seamlessly.  
  Inspired by Niri (infinite scrolling), with natural interactions (minimal learning curve) and separated window lifecycles (window disappears but its position remains).  
  Planned languages: C++ or Rust, maybe River WM.  
  *Not started yet*
